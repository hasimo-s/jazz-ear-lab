# Jazz Ear Lab

ジャズに特化したイヤートレーニング Web アプリ（MVP 開発中）。

## 現在の実装状況

| 機能 | 状態 |
|---|---|
| インターバル認識（旋律的2音、上行/下行/両方、初級・中級・上級、キー・音域ランダム） | ✅ 最小版 |
| 問題画面（再生・回数無制限・4択・正誤・正解表示・解説・正解音/自分の回答の再生・次へ） | ✅ |
| キーボード操作（Space/R=再生、1〜4=回答、A=正解音、S=自分の回答、Enter/N=次へ） | ✅ |
| 学習履歴（カテゴリ別/項目別の正答率、回答履歴、再生回数、回答時間、苦手の復習） | ✅ 基本版（IndexedDB） |
| 5画面（ホーム・カテゴリ選択・問題・結果・履歴） | ✅ |
| コード認識（初級: 三和音・7th／中級: 7th系・sus4／上級: テンション・alt、分散和音再生、構成音の違いの解説） | ✅ |
| コード進行認識 | ❌ 未実装（設計のみ） |
| 英語UI | ❌ 未実装（文字列は `src/i18n/ja.ts` に分離済み） |

設計・データモデル・テスト設計・技術リスクは [docs/DESIGN.md](docs/DESIGN.md) を参照。

## 起動

Node.js 20 以上（22 で確認）。

コマンドに慣れていない場合: Node.js を https://nodejs.org からインストールし、展開したフォルダでターミナルを開いて下の3行目まで実行します。

```bash
npm install
npm run dev        # http://localhost:5173 （初回に音源を public/samples/piano へコピー）
npm run build      # 本番ビルド → dist/
npm run preview
```

`?seed=12345` を URL に付けると、セッションの問題を再現できます（問題画面の下部に現在のシードを表示）。

## テスト

```bash
npm test           # Vitest: 音楽理論・問題生成（音程/コード）・曖昧さ検証・採点・集計・IndexedDB
npm run typecheck
npm run e2e        # Playwright: ビルド → preview サーバを起動し、デスクトップ / Pixel 7 エミュレーションで実行
```

Playwright のブラウザが未導入の環境では `npx playwright install chromium` を実行してください（`/opt/pw-browsers/chromium` がある環境ではそれを使います）。

## 既知の制約

- 自動テストで確認しているのは「正しい音の再生を要求したこと」と「音源ファイルが読み込めたこと」まで。**実際に聞こえる音・音質は自動検証していません**。
- iOS Safari / Android Chrome の実機では未検証。iOS のサイレントスイッチ ON 時は音が鳴らない可能性があります。
- 初回再生時に約4MB の音源を読み込みます。読み込めない場合は簡易シンセで再生し、画面に表示します。
- 増4度/減5度など、旋律的2音では区別できない異名同音は1つの選択肢にまとめています。
- コード問題は常にルートをベース（最低音）に置いています。転回形のベース（C/E など）や、ルートレス・ボイシング単体での出題は未対応です。
- コードのボイシングは規則で自動生成しています（低音域の濁りを避ける簡易ルールあり）。演奏家が選ぶボイシングと比べて不自然な配置が出る可能性があり、聴感での確認が必要です。
- 学習履歴は端末のブラウザ内のみ。ブラウザのデータ消去・プライベートモードで失われます。
- 回答時間は「問題表示（自動再生開始）から回答まで」です。
